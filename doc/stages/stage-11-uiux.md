원 PLAN.md에서 이연된 항목들을 모두 처리.

- **Phase 11.1**: 탑뷰 카메라 토글 (`V` 키).

## Phase 11.1 — 탑뷰 토글

### 결정사항
- `V` 키 토글: NORMAL ↔ TOP_DOWN.
- NORMAL: `minPolarAngle=0, maxPolarAngle=π·0.49` (현재).
- TOP_DOWN: `minPolarAngle=0.04, maxPolarAngle=0.25` — 거의 위에서 살짝 기울여 봄. 완전 수직(0)은 조준 방향 계산이 무너지므로 약간의 각도 유지.
- TOP_DOWN 진입 시 카메라 거리를 자동으로 4m 정도로 셋업해 전체 테이블 가시. 복귀 시 1.5m로.
- HUD에 현재 모드 표시.

### 검증
- `V` 키 → 카메라 모드 토글.
- TOP_DOWN에서도 조준 가능 (큐 스틱·조준선 정상).

## Phase 11.2 — Ball-in-hand 자유 배치

### 결정사항
- **모든 파울**에서 ball-in-hand 부여 (현재는 스크래치만).
- 게임 상태: `BALL_IN_HAND` 추가.
- UI: 큐볼이 마우스 위치에 떠 있고, 클릭 시 그 위치에 확정. 다른 공·쿠션과 겹치면 살짝 밀어내거나 클릭 차단.
- 마우스→베드 평면 좌표 변환: `THREE.Raycaster`로 bed 메시와 교차.
- 배치 후 자동으로 WAITING_FOR_SHOT 전이.
- 안내 메시지: "Ball in hand — click to place"

### 검증
- 의도적 파울(잘못된 그룹) → ball-in-hand 상태.
- 마우스 이동 시 큐볼이 따라옴 (포인터 위치).
- 클릭 → 배치 완료, 정상 샷 가능.
- 다른 공 위 클릭 차단(또는 가장 가까운 자유 위치로 보정).

## Phase 11.3 — 공 번호 텍스처

### 결정사항
- 절차적 canvas 텍스처. 각 공의 번호+색을 캔버스에 그려 `THREE.CanvasTexture`로 변환.
- 솔리드(1-7): 단색 + 흰 원 + 번호.
- 8: 검정 + 흰 원 + "8".
- 스트라이프(9-15): 흰 적도 띠 + 띠 위에 흰 원 + 번호. 현재 자식 Cylinder 띠는 제거하고 텍스처로 대체.
- 큐볼(0): 순백, 번호 없음.

### Sphere UV
- u: 경도 0~1 (적도 한 바퀴).
- v: 위도 0(남극) ~ 1(북극).
- 번호 원: 적도 부근(v=0.5, u=0.5)에 배치.

### 검증
- 16개 공 각각 번호 식별 가능.
- 스트라이프 띠가 자연스럽게 보임.
- 텍스처 메모리/성능 정상.
