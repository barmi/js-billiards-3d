## Phase 7.1 — 최종 QA + README/PLAN 갱신

### 점검 체크리스트

#### 정적 배포 동작
- [x] `src/` 디렉토리만으로 정적 서버에서 동작 (이미 `python -m http.server`로 확인).
- [x] 외부 의존성은 importmap을 통한 unpkg ESM 로드 (three@0.184.0, cannon-es@0.20.0). 빌드 도구 불필요.
- [x] 페이지 로드 시 콘솔 에러 없음.

#### 게임플레이 종단-종단
- [x] 페이지 진입 시 9피트 표준 테이블 + 15개 객체구 랙 + 큐볼 헤드 스팟에 정상 배치.
- [x] 카메라 드래그(OrbitControls), 휠 줌, 큐볼 따라 회전.
- [x] 스페이스바 차지/릴리스로 샷 발사. 풀파워 8 m/s.
- [x] 조준 어시스트 라인이 큐볼 → 첫 충돌(공 또는 쿠션) 표시.
- [x] 공-공/공-쿠션 물리 자연스러움. 포켓 진입 시 가라앉음 + 350ms 후 제거.
- [x] 큐볼 스크래치 시 헤드 스팟에 자동 재배치.
- [x] 턴 표시(P1/P2 pill), 그룹 배지(S/St), 포켓된 공 점수.
- [x] 최근 샷 결과 메시지(브레이크/포켓/파울/턴 패스).
- [x] 8볼 합법 포켓(그룹 클리어+무파울) → 슈터 승. 조기/파울 포켓 → 슈터 패.
- [x] Game Over 오버레이 + New Game 버튼(리로드).

#### 단위 정합성
- [x] WPA 9피트 풀 표준 치수: 플레이 면 2.54 × 1.27 m, 공 지름 57.15 mm, 공 무게 0.17 kg.
- [x] 좌표계: y=0 베드, x=긴 변, z=짧은 변.

### 의도적 제한 / 이연 항목

다음은 의도적으로 제외했으며 향후 이터레이션 대상:

- **스핀(잉글리시)**: ball-cloth 마찰 모델 + 임팩트 포인트 매핑 필요. Stage 4 Phase 4.3.
- **탑뷰 카메라 토글**: 직관적이지만 조준 모델을 별도 처리해야 함. Stage 6 Phase 6.2.
- **공 번호 텍스처**: 솔리드/스트라이프 식별은 색+띠로 가능. 번호 텍스처는 추가 폴리시.
- **사운드 효과**: 충돌·포켓 사운드.
- **Ball-in-hand 자유 배치**: 현재는 스크래치 시 헤드 스팟 자동 배치. 마우스로 자유 배치 가능하게.
- **AI 단일 플레이어**: 현재는 2인 로컬만.
- **모바일 터치 컨트롤**: 데스크톱 OrbitControls + 키보드 차지에 최적화.

### 배포 방법

`src/`를 정적 파일 호스팅으로 배포(GitHub Pages, Netlify, Vercel, S3 등).

로컬 미리보기:
```bash
cd src
python3 -m http.server 8080
# 또는
npx http-server -p 8080
```

`file://` 직접 열기는 ES Modules CORS 제약으로 동작하지 않음.
